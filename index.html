Sua chave da API da Anthropic

  
A IA que cria os jogos roda pela API da Anthropic. Cole sua chave (começa com sk-ant-), que você cria em console.anthropic.com. Ela fica salva só neste navegador e é enviada apenas para a Anthropic.

  
  

    
    
  




  
Gerar APK pelo GitHub

  
  
  
    
    
  1. Baixe o jogo.
    2. 
    
  2. Crie um repositório no GitHub (entre na sua conta). Dê um nome, deixe marcado Add a README file e toque em Create repository.
    3. 
    
    4. 
    
  4. Envie o jogo. Na página que abrir, toque em “choose your files”, escolha o index.html e toque em Commit changes.
    5. 
    
  5. Crie o gerador de APK. Já vem tudo preenchido, é só tocar em Commit changes e confirmar.
    6. 
    
  6. Espere uns 8 minutos, abra a execução com ✓ verde e baixe jogo-apk em Artifacts. Descompacte o zip: dentro está o app-debug.apk para instalar.
    7. 
  

  

  
Se alguma página do GitHub vier cortada no celular, ative “Site para computador” no menu do navegador.
